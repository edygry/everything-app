# Everything App - Tech Spike

Recruiting-first ownership model. Cross-platform from day one.

## Tech Stack

- **Frontend:** Vue 3 + TypeScript + Pinia + Vue Router
- **Build:** Vite
- **Deployment:** GitHub Pages

## Getting Started

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Features

- Auth simulation (phone/email)
- Ownership balance display
- Tokenomics visualization
- Recruit simulation
- Rank progression system

## Tokenomics

- **Total Supply:** 1 trillion tokens
- **SPV Equity Pool:** 20% of OpCo common stock
- **Daily Decay:** 0.15% of current holdings
- **Daily Activity Bonus:** 0.08% of current holdings
- **Direct Recruit Bonus:** 100,000 tokens
- **Vesting:** 30-day cliff, then linear over 90 days
